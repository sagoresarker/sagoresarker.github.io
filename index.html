Selected work

Agent cloud

MicroVM platform

A platform that runs headless AI coding agents in hardware-isolated microVMs, one per session: a control plane, a per-host worker and an in-guest init, with live output streaming, persistent volumes and snapshots to object storage.

The hard part: isolation without leaking secrets. Egress is deny-by-default per VM, real credentials are injected at the egress proxy and never enter the guest, and hosts dial out so no host exposes an inbound port.

Rust · Firecracker · Cloud Hypervisor · KVM · PostgreSQL · S3
